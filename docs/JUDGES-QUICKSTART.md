# 评委快速上手：从订单到人才执行反馈

本指南对应2026-10-31修复版。全部人员、岗位、订单均为虚构。评委可在演示人员已启动的本地页面直接操作；无需GitHub账号、模型密钥或真实员工资料。

## 先打开页面

演示人员默认提供 http://127.0.0.1:3225；该地址指运行服务的同一台电脑，不是公网网站。如果使用README默认启动方式，则地址为 http://127.0.0.1:3220。先确认演示人员实际使用的端口。

若需自己启动，先安装Node.js 22.13或以上版本，在项目目录执行下列命令。已有依赖时跳过npm ci。为保护其他人的业务数据，使用单独的演示目录；以下macOS命令创建新的临时目录，不清空旧库。

```sh
npm ci
npm run build
people_lab_demo_dir=$(mktemp -d /tmp/people-lab-judges.XXXXXX)
HRFLOW_PORT=3225 HRFLOW_DATA_DIR="$people_lab_demo_dir" npm start
```

保持终端运行，浏览器打开3225。停止服务用Ctrl+C。数据保存在刚创建的目录；如要继续同一次演示，记录终端中的目录变量并复用该目录，不重新建立空库。Windows使用README启动方式；需要隔离数据时先设置HRFLOW_DATA_DIR再启动。

## 推荐演示路线

以下是建议的3–5分钟讲解顺序，不是实测耗时；由演示人员控制节奏。无须把所有后台维护都交给评委。

|步骤|实际操作|应看到什么|说明什么|
|---|---|---|---|
|1|顶部保持HR身份，先进入SkillBridge，点“载入内部人才演示样例”；再进“生产需求”，点“载入 / 重置演示样例”|虚构转岗员工、订单、资格和班次可用|两个样例都在最终计算前载入，避免刚确认就过期；会写入虚构记录和版本，不是只读预览|
|2|核对每日数量与范围，勾选完整性确认，点“确认输入并计算”|需求10.00h、分配8.00h、缺口2.00h|缺口由工时和合格共享容量确定，不是AI猜人数|
|3|点“HR 确认结果”，再点“前往 SkillBridge 分析”，点“发起 SkillBridge 分析”|内部人才证据、调配/培养/招聘选项与风险|已分配满8h的检验员没有可重复提供的增量|
|4|选择内部培养，点“HR 审核”，填写审核说明并批准|状态变为已批准，尚未执行|人工批准与实际写入是两件事|
|5|点“执行方案”再“确认执行”，点“查看已创建的培训任务”|立即看到真实任务、员工、来源与回链|培养落到任务，但不自动授予岗位资格|
|6|返回原分析，可独立批准并执行外部招聘方案，前往招聘工作台|真实招聘需求草稿；可关联已有候选人|没有自动生成人选，没有自动录用|
|7|刷新页面，重新查看相关任务/草稿|业务记录仍在|当前使用真实持久化，而非只改画面|

载入样例会更新记录、使已有计算过期；只在专用虚构演示库内操作。不要点全局“重置演示数据”来恢复这一流程。stale时重新核对并计算，保留历史；blocked时按缺项说明补录。

## 可选：展示缺口真正关闭

请演示人员在独立案例完成下列操作，评委观察前后结果。该步骤表示正式资格核验这一外部事实被授权录入，不应说成培训自动产生了能力。

1. 在“生产需求”的数据类型选择“技能及岗位资格”，展开“结构化录入、查看与版本维护”。
2. 点击记录 `skillbridge-demo-qualification`，将结构化记录中的 `status` 从 `unverified` 改为 `verified`。检查员工仍为 `emp-skillbridge-demo`、技能为 `inspection`、等级为2、类型为 `quality-auth`，有效期覆盖需求完整窗口；来源必须对应本次虚构核验依据和责任人。保留原编号与当前版本，点“保存为新版本”。不要点“保存新记录”重复建档。
3. 原计算显示stale，旧结果不能继续执行。保留原每日数量与范围，重新核对完整性、计算并由HR确认。
4. 应看到10h需求、10h分配、0h缺口；旧10/8/2仍在历史里。进入SkillBridge后不再显示该已关闭缺口。若数据不同，不强改结果或清库，检查资格、日历与新增订单影响。

上述数值仅对应本指南的标准独立样例。已有其他订单或占用时，实际结果可能不同；系统不能为满足讲解而覆盖业务事实。

## 评委可提问的三个边界

- “为何不直接调配原员工？”原8h已经用于订单；主管签字不能创造额外工时。容量不足会被服务端拒绝。
- “完成培训是否已能上岗？”不能。需正式资格记录、足够等级、全部资格类型及完整有效窗口。
- “这是自主AI人事决策吗？”不是。分析与问答采用确定规则/预置资料；HR审批、主管风险确认和真实业务约束保留。演示身份不是真实登录。

当前不支持分钟级或多日借调排程；无法安全表达部分时段承诺时明确阻断。没有未经测量的效率、准确率或节省金额承诺。更多操作见[使用说明](USER-GUIDE.md)，证据范围见[验证记录](VALIDATION.md)。
