# HR-V1 · HRFlow AI 本地交互 Demo

发布日期：2026-10-30。

首个可运行版本，面向制造企业 HR 场景，打通同一人的招聘、入职、员工服务、请假审批、岗位培训与管理统计。采用 React + TypeScript + Vite、Express 与 SQLite，无需模型密钥；首次安装依赖、完成构建后可离线演示。

## 本版功能

- 招聘工作台：一个质量检验员岗位、三位虚构候选人，能力证据、简历原文、待核实项、面试建议与 HR 确认录用。
- 入职管理：清单核验、员工身份激活、岗位必修培训和 HR 确认的培养任务自动分配。
- 员工服务：制度咨询、版本及原文引用、未知问题转人工工单；单日全天或半天年假的预览、提交和状态查询。
- 主管审批：批准或附原因拒绝；批准后一次性扣减年假余额，重复请求不会重复扣减。
- 岗位培训：SOP 学习、不合格品处理情境演练、四项规则评分、遗漏反馈与唯一复练任务。
- 管理驾驶舱：招聘漏斗、事务状态、能力证据覆盖、部门人数、待办与操作时间线，图表使用实际演示业务数据。
- 三种演示身份、SQLite 持久化、确认后重置、Windows 一键启动与停止。

## 验证

发布副本完成 `npm ci`、`npm run build`、`npm test` 和 `npm run test:e2e`。接口测试 14 项、浏览器验收 21 项通过；测试使用隔离数据库，不修改本机正在运行的演示记录。详细结果见 [验收记录](../验收记录.md)。

## 使用

克隆仓库后，Windows 双击 `启动HRFlow.cmd`，或运行：

```sh
npm ci
npm run build
npm start
```

访问 <http://127.0.0.1:3220>。完整说明见 [README](../../README.md)。

## 当前边界

本版本的“AI”使用预置资料和确定性规则。未接入真实大模型、任意简历文件解析、向量检索、生产登录或外部 HR 系统。所有人物、企业制度及业务资料均为演示数据。仓库不包含本机数据库、运行日志、依赖目录或模型凭据。未接入当前运行入口的后续 UI 设计草稿未纳入本版本。
