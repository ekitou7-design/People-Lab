## 调配成功的限制与正确成功路径

当前 Order2People 自动分配窗口内所有合格可用人员。若还有2h缺口，同一计算中已分配满8h的人不可能再凭相同8h补足；主管签字不能创造容量。原调配成功测试错误地要求这一行为，现改为断言409、零占用和真实缺口不变，不能恢复旧错误期待。

调配并未实现分钟级排程。已有日桶 allocations 不包含可证明的部分执行区间；不能取需求窗口前2h虚构安排。ASSIGNMENT_INTERVAL_REQUIRED 保留为明确产品限制，不声称已验证部分时段调配成功。要支持该能力，应另行设计可追溯的真实供给变更和可核验区间，保留整数秒、共享容量、同订单承诺不双扣与外部占用扣除规则。

本轮成功路径使用既有虚构转岗员工：原正式资格为 unverified → 有权限的资格维护操作明确更新为 verified → 旧计算 stale → 人工重新核对范围并计算 → 10h需求/10h分配/0h缺口 → HR确认 → SkillBridge不再列出已关闭缺口。没有改写历史或新增虚构人选掩盖标准案例。培训创建或通过始终不能授予资格。
